# Firebase Studio

This is a NextJS starter in Firebase Studio.

To get started, take a look at src/app/page.tsx.

## Deployment to Netlify

This project is configured for easy deployment to Netlify.

1.  **Push to Git**: Make sure your code is pushed to a GitHub, GitLab, or Bitbucket repository.
2.  **Sign up/Log in to Netlify**: Go to [app.netlify.com](https://app.netlify.com/).
3.  **Import Project**: Click "Add new site" > "Import an existing project" and choose your Git provider.
4.  **Select Repository**: Select the repository for this project.
5.  **Deploy**: The build settings will be automatically detected from the `netlify.toml` file. Simply click "Deploy site".

Netlify will then build and deploy your application. Any data you've saved via the admin panel will be stored in Netlify Blobs.
